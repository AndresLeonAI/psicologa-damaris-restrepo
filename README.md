# Damaris Restrepo · Psicóloga clínica en Medellín

Sitio de una página, estático y sin dependencias (HTML + CSS + JS), publicado en GitHub Pages.

- `index.html`: contenido, metadatos SEO/Open Graph y JSON-LD.
- `styles.css`: identidad visual (papel crema, tinta turquesa, Fraunces + Manrope).
- `main.js`: parallax por capas con `transform`, revelado al hacer scroll, navegación que se oculta al bajar. Respeta `prefers-reduced-motion`.
- `assets/hero.mp4` / `hero.webm`: video del hero en 1080p, bucle perfecto de 12 s (tinta turquesa en agua, renderizado con shader GLSL propio), más su fotograma póster.

Toda la información proviene de su perfil profesional público (Doctoralia).
